10.3 Three conventions

Absolute paths live in one file — common/R/paths.R, which contains none itself.

reference-code/ is never sourced or executed by the registered runnable layer. Verification may read it as text/data to check digests, banners, and the archival-safety certificate. verification/verify_quarantine.py audits the source/import/subprocess boundary, and a cold build is rehearsed with the whole directory unavailable.

The runnable build does not depend on the companion paper’s research tree. The copied receipts and archival evidence legitimately retain those provenance strings; they are outside this narrower execution claim. The exact public file set is checked against provenance/release-files.csv.
